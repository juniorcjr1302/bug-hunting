# 🐛 Caça aos Bugs

Página web temática ("Departamento Municipal de Caça aos Bugs") com **18 bugs plantados
de propósito** em HTML, CSS e JavaScript, feita como exercício prático de debugging.

## 🎯 Objetivo

Os alunos abrem a página, interagem com ela (clicando, digitando, enviando formulário)
e vão anotando tudo que parece estranho. Depois, a turma discute em conjunto qual é
o código correto de cada bug encontrado.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (vanilla, sem framework)

## ▶️ Como rodar

Basta abrir o arquivo `index.html` no navegador. Não precisa de servidor nem instalação.

## 📚 Contexto

Projeto de extensão da disciplina do 4º período de Análise e Desenvolvimento de Sistemas —
**Uninassau Caxangá**.

## 🐞 Sobre os bugs

Os bugs estão distribuídos entre:
- 6 bugs de **CSS** (visuais)
- 6 bugs de **JavaScript** (comportamentais)
- 6 bugs de **HTML** (estruturais)

O gabarito está em comentários no próprio código (marcados como `BUG #N`), visível
só pra quem abre os arquivos — os alunos veem só o resultado no navegador.
